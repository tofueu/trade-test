# Trade Test：舊＋新策略兩份 Top 100（2026-10-30）

此為**既有歷史回測輸出的重新篩選與排名**，不是本次重新運算 9,556 + 336 組策略，也尚未完成 TradingView 一致性。不同市場與週期的報酬不代表同風險。

## 資料範圍
- 舊研究：`results/complete_ranking_9556.csv.gz`，9,556 列五年日線策略配置，資料期間 2021-10-10 至 2026-10-10（UTC，含開始不含結束），原 README 記載 Binance / Yahoo Finance 歷史 K 線；未提供每列可獨立驗證的原始行情 manifest。
- 新研究：`results/intraday/new_BTCUSDT_{週期}_five_year_ranking.csv`，12 種週期（1m / 3m / 5m / 15m / 30m / 1h / 2h / 4h / 6h / 8h / 12h / 1d）共 336 列，BTCUSDT；配有五年 Binance USD-M 歷史資料 provenance。
- 上述兩份來源有策略重疊、但不能直接視為獨立回測或逐筆 parity 證明。

## 篩選與計數
1. 五年收益嚴格 `>100%` 且實際回測成交數 `>=70`（訊號次數不代替實際成交），最大回撤介於 `0~100%`，非數值結果捨棄；新研究限 `資料完整=True`。
2. 每一個 `商品 × 週期 × 策略名稱 × 出場方式` 僅保留一組收益最高的倉位方案，以免全/半 Kelly/固定部位重複佔據排名。**這是去重後的策略配置，不等於策略家族數。**
3. 依收益 Top100：將合格去重配置按五年收益率遞減。
4. 依策略 Top100：先按 `舊/新 × 策略名稱` 的最佳收益排列策略群組，再逐群各取一列、循環取到 100 列；呈現時按策略群組及群組內收益排序，讓不同策略都有席位，而非被單一策略的多商品配置淹沒。
5. OOS 報酬、回撤與勝率列為風險參考，**本版不是正 OOS 或風險調整排名**。多個結果的 OOS 為負，不能僅看五年總收益。
6. 舊研究的七個「新增」策略也包含在舊日線資料中；這裡「新」是指 12 種週期的新一輪 BTC 五年回測。跨來源同一商品、同一週期、同一策略、同一出場法採上述去重；仍可能存在策略規則近似但名稱不同的別名。
